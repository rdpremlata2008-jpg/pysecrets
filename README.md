# PySecrets

A fun Python Easter egg library created by Shaswat.

Explore Python's Zen, Matrix-style text, secret messages, and other
programming Easter eggs.

## Installation

```bash
pip install pysecrets-easter
````

## Quick Start

```python
import pysecrets

pysecrets.zen()
```

## Available Easter Eggs

### Python's Zen

```python
import pysecrets

pysecrets.zen()
```

### Matrix Animation

```python
pysecrets.matrix()
```

Customize the animation:

```python
pysecrets.matrix(lines=20, width=60, delay=0.02)
```

### Hacker Animation

```python
pysecrets.hack()
```

This is a fictional animation. It does not hack computers or networks.

### Secret Message

```python
pysecrets.secret()
```

### Konami Code

```python
pysecrets.konami()
```

### PyDunio Easter Egg

```python
pysecrets.pydunio()
```

### Interactive Menu

```python
pysecrets.discover()
```

### Help

```python
pysecrets.help()
```

### Version

```python
pysecrets.version()
```

## Requirements

* Python 3.8 or newer
* No external dependencies
